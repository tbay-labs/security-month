What is this campaign?

The September Security Streak is a week-long event to educate users on safe trading practices, rewarding you with daily coins and a chance to win up to ₦250,000 in coupons.

How it works

Complete one security task each day. Collect coins for eligible on-time tasks, which are credited on the reward distribution date. Complete all 7 tasks to qualify for the Grand Prize.

Terms & Conditions

  • 1. Campaign Period: Starts September 8th, 2026, and ends September 14th, 2026.

  • 3. Streaks & Missed Tasks: You only earn coins and a streak check-in by completing the active day's task. If you miss a task, you can still complete it later to qualify for the Grand Prize, but it will award 0 coins.
  • 4. Eligibility: Only valid Tbay users who successfully submit legitimate screenshots and answers will qualify for rewards.
